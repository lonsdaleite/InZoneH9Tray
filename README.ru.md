# InZoneH9Tray

[English](README.md) | **Русский**

Индикатор батареи и опциональное автопереключение звука для Sony INZONE H9 первого поколения (WH-G900N) в Windows. Основан на [janit88/InZoneH9Tray](https://github.com/janit88/InZoneH9Tray).

## Использование

Запустите `InZoneH9Tray.exe`. В меню значка в трее:

- **Auto-switch audio output** — галка автопереключения. При первом запуске выключена; состояние сохраняется.
- **Start with Windows** — запуск при входе текущего пользователя в Windows, без прав администратора. Включается только вручную через меню.
- **Refresh now** — обновить данные; запрос выполняет тот же рабочий поток.
- **Open data folder** — открыть настройки и журнал диагностики.
- **Exit** — завершить программу, оставив текущий аудиовыход выбранным.

При включённой галке подключение гарнитуры выбирает **INZONE H9 / INZONE H7 - Game**. При отключении программа возвращается на последний выбранный доступный выход вне этой гарнитуры. Ручной выбор выхода запоминается и при выключенной галке. Если выбрать другой выход при уже подключённых наушниках, программа не отменяет этот выбор до следующего изменения подключения.

Меняются только выходы воспроизведения для обычного звука и мультимедиа. Выбор микрофона и выход по умолчанию для связи сохраняются. Приложения с явно заданным аудиоустройством могут не следовать системному переключению.

Если последний выход неизвестен или недоступен, используется автоматический выбор Windows среди остальных выходов. Когда вариантов несколько, для этого кратковременно отключаются активные выходы Game/Chat, считывается выбор Windows, затем доступность выходов восстанавливается и применяется выбранный вариант. В этом запасном сценарии текущие аудиосессии могут прерваться. Файл восстановления позволяет вернуть доступность выходов при следующем запуске после прерванной операции. Обычный возврат на запомненный выход не отключает устройства.

## С Hub и без Hub

- **Hub закрыт или не установлен:** адаптер определяется по `VID_054C&PID_0E53`. Программа читает состояние радиосвязи и батареи через COM, освобождая порт после каждого опроса.
- **Hub работает:** встроенный компонент примерно раз в три секунды читает текущие поля подключения и батареи в Hub, в том числе когда Hub свёрнут в трей. COM-порт остаётся за Hub. `%APPDATA%\Sony\INZONE Hub\ActionLog.log` дополняет эти данные событиями между опросами и служит резервом, если прямое чтение недоступно. Пустой или отсутствующий журнал не мешает прямому чтению статуса.
- Если ни один источник не даёт пригодного состояния, статус считается **неизвестным**, переключения не происходит.

Поля состояния и журнал — внутренние интерфейсы Hub, проверенные с версией 1.0.19; после обновления Sony они могут измениться. Встроенный компонент через ClrMD читает небольшой известный набор объектов без остановки Hub, внедрения кода, сохранения дампа или отправки данных. Чтение работающего процесса не гарантирует согласованность: проверяются две совпавшие выборки, типы объектов, устройство и признаки завершения инициализации; при ошибке остаётся резервный журнал. На вызов отведено не более пяти секунд. При запуске Hub последнее подтверждённое чтение COM сохраняется до пяти секунд. Программа не включает телеметрию и не меняет настройки Hub. Если запуск Hub совпадёт с коротким COM-запросом, Hub может потребоваться повторная попытка открытия порта.

Меню трея поддерживает масштабирование Windows отдельно для каждого монитора, в том числе при разных настройках масштаба.

Прямые ответы о подключении H9 и события соединения Hub проверены на устройстве. H7 использует тот же ID адаптера, но отдельно не проверен. H9 II и INZONE Buds этим протоколом не поддерживаются.

## Значок и данные

| Значок | Значение |
| --- | --- |
| Число | Последний сообщённый процент заряда |
| ON | Гарнитура подключена, процент пока неизвестен |
| OFF | Гарнитура отключена или адаптер отсутствует |
| ? | Состояние неизвестно / ожидается |

Файлы хранятся в `%LOCALAPPDATA%\InZoneH9Tray`:

- `settings.json` — галка и последний внешний выход.
- `inzone_battery.txt` — процент; удаляется, когда значение недоступно.
- `inzone_battery_status.txt` — статус и источник (`Hub`, `COM`, `USB`).
- `inzone_tray_error.log` — журнал диагностики с ограничением размера.
- `audio-recovery.json` — незавершённое восстановление аудиовыходов.

Одновременно работает один экземпляр в сеансе Windows. Служба не устанавливается, драйверы не меняются. Галка **Start with Windows** добавляет текущий путь EXE в `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` под именем `InZoneH9Tray`; снятие галки удаляет эту запись. Перед включением положите EXE в постоянную папку. Если переместите или переименуете файл, включите опцию из нового расположения, чтобы обновить запись. Если приложение уже запущено, повторный автоматический запуск завершается без сообщения.

## Разработка и сборка

Для сборки нужны Windows 10/11 x64, Python 3.11+ и .NET SDK 8 или новее. Готовый EXE включает среду выполнения вспомогательного компонента; устанавливать .NET отдельно не нужно.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
dotnet publish hub_snapshot/HubSnapshot.csproj -c Release -o build/hub-snapshot --source https://api.nuget.org/v3/index.json
python -m unittest discover -s tests -v
python inzone_tray.py --diagnose
python inzone_tray.py
```

Режимы `--status` и `--diagnose` только читают состояние, не переключая аудиовыход. Перед диагностикой закройте другой экземпляр программы.

Для сборки из активированного окружения запустите `./build.ps1`. Скрипт собирает вспомогательный компонент, запускает тесты и включает компонент и DPI manifest в EXE.

Результат: `dist\InZoneH9Tray.exe`. Автоматические тесты используют подставные аудиоустройства и не переключают реальный звук. Для выбора выхода используется закрытый интерфейс Windows `IPolicyConfig` через pycaw; после крупных обновлений Windows совместимость нужно проверять.
